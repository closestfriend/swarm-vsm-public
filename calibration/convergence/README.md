# Reading the convention test

The historical [results note](RESULTS.md), [preregistration](PREREG.md) and numerical outputs are preserved unchanged. This clarification accompanies submission preparation on 8 November 2026.

The defensible result is that none of the tested conventions showed above-chance page-exposure lift after the specified multiple-testing correction. The sentence in RESULTS.md saying conventions "are not learned page by page" is stronger than this test establishes. Likewise, an off-page source of S5 is a possible interpretation, not a demonstrated location.

Shared model or prompt priors, coordination on unobserved channels, and agents arriving with established conventions are possible explanations. Limited power, incomplete histories, the per-page record cap, unauthenticated handles and exposure measured as an opportunity to read also limit what the null can exclude. A one-sided p-value near 1 is not a separate test establishing negative lift.

Use the numerical table as the recorded result and these qualifications when summarising it. This study does not by itself establish the presence, absence or source of swarm-level governance.
